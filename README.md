## Deskripsi Tugas Pertemuan 1

Tugas ini bertujuan untuk memahami konsep platform **Web**, **Desktop**, dan **Mobile**, menyiapkan lingkungan pengembangan dasar, serta menganalisis perbedaan karakteristik tiap platform. Isi tugas meliputi:

1. **Setup environment**: instalasi tools pengembangan dan pengecekan versinya lewat terminal.
2. **Analisis komparatif platform**: tabel perbandingan Web, Desktop, dan Mobile beserta penjelasan detail dan referensi (`analisis-platform.md`).
3. **Refleksi**: pengalaman, tantangan, dan rencana mengatasi kendala saat setup (`refleksi.md`).
4. **Dokumentasi**: commit dan push ke GitHub, serta laporan PDF yang dikumpulkan di LMS.
